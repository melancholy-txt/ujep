# Expo Sample App

A simple Expo React Native application with a counter interface.

## Features

- Simple counter with increment and reset buttons
- Clean UI with styled components
- Works on iOS, Android, and Web platforms

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI

## Installation

1. Install dependencies:
```bash
npm install
```

2. Or with yarn:
```bash
yarn install
```

## Running the App

### Start the development server:
```bash
npm start
```

### Run on specific platforms:

**Android:**
```bash
npm run android
```

**iOS:**
```bash
npm run ios
```

**Web:**
```bash
npm run web
```

## Project Structure

- `App.js` - Main application component
- `package.json` - Project dependencies and scripts
- `app.json` - Expo configuration
- `babel.config.js` - Babel configuration

## What's Included

- React Native basic UI components
- Hooks (useState) for state management
- Styling with StyleSheet
- TouchableOpacity for button interactions
- Status bar component
