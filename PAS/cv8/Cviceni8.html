Vypocty pravdepodobnosti

Diskretni rozdeleni

Binomicke rozdeleni: n-krat opakuji pokus, kde muze nastat uspech s pravdepodobnosti p nebo neuspech s pravdepodobnosti (1 - p) dulezite je, aby pravdepodobnost uspechu byla ve vsech pokusech stejna parametry: n - pocet pokusu, p - pst uspechu pbinom(k, n, p) - distribucni funkce P(X <= k) dbinom(k, n, p) - pravdepodobnostni funcke P(X = k)

Hypergeometricke rozdeleni: v osudi mam N kouli, w bilych a b cernych, vytahnu n kouli BEZ VRACENI a pocitam, kolik jich je bilych pravdepodobnost tazeni bile koule je v kazdem tahu jina Parametry: w - pocet bilych kouli v osudi, b - pocet cernych kouli v osudi n - pocet kouli tazenych z osudi phyper(k, w, b, n) - distribucni funkce P(X <= k) dhyper(k, w, b, n) - pravdepodobnostni funcke P(X = k)

Geometricke rozdeleni: n-krat opakuji pokus, kde muze nastat uspech s pravdepodobnosti p nebo neuspech s pravdepodobnosti (1 - p) pocitam pocet tahu pred PRVNIM uspechem, pravdepodobnost p musi byt v kazdem tahu stejna Parametr: p - pravdepodobnost uspechu pgeom(k, p) - distribucni funkce P(X <= k) dgeom(k, p) - pravdepodobnostni funcke P(X = k)

Poissonovo rozdeleni: pocet jevu za casovou jednotku, kdyz znam prumerny pocet jevu za tuto jednotku Parametr: lambda - stredni hodnota (prumerny pocet jevu za casovou jednotku) ppois(k, lambda) - distribucni funkce P(X <= k) dpois(k, lambda) - pravdepodobnostni funcke P(X = k)

Vypocty pravdepodobnosti

P(X = k) … pravdepodobnostni funkce v bode k P(X <= k) … distribucni funkce v bode k P(X < k) = P(X <= (k - 1)) … distribucni funkce v bode k - 1 P(X > k) = 1 - P(X <= k) … jedna minus distribucni funkce v bode k P(X >= k) = 1 - P(X <= (k - 1)) … jedna minus distribucni funkce v bode k - 1 P(k <= X <= l) = P(X <= k) - P(X <= (l - 1)) … rozdil distribucnich funkci v bodech k a l - 1

Spojita rozdeleni

Normalni rozdeleni: Parametry: mu - stredni hodnota, sigma - smerodatna odchylka pnorm(x,mu,sigma) - distribucni funkce P(X <= x) qnorm(p,mu,sigma) - kvantilova funkce: x tak, ze P(X <= x) = p

# Grafy normalniho rozdeleni N(180, 49): vyska dospelych muzu

# hustota
curve(dnorm(x, 180, 7), from = 150, to = 210, main = "Hustota N(180, 49)", col = "red", ylab = "Hustota")

# distribucni funkce
curve(pnorm(x, 180, 7), from = 150, to = 210, main = "Distribucni funkce N(180, 49)", col = "purple", ylab = "Hustota")

# pravdepodobnost, ze nahodne vybrany muz bude mensi nez 170 cm

Lognormalni rozdeleni: velicina, jejich logaritmus ma normalni rozdeleni Parametry: mu , sigma (velicina ln(X) ~ N(mu, sigma^2)) plnorm(x,mu,sigma) - distribucni funkce qlnorm(q,mu,sigma) - kvantilova funkce stredni hodnota exp(mu+sigma^2/2) rozptyl (exp(sigma2)+2)exp(2mu+sigma2)

Exponencialni rozdeleni: doba cekani do udalosti Pramater: int - intenzita pexp(x,int) - distribucni funkce qexp(q,int) - kvantilova funkce distribucni funkce P(X <= t) = 1 - exp(-int*t) stredni hodnota 1/int rozptyl 1/int^2

Vypocty pravdepodobnosti

P(X = k) = 0 pro libovolne k!!! P(X <= k) = P(X < k) … distribucni funkce v bode k P(X >= k) = P(X > k) = 1 - P(X <= k) … jedna minus distribucni funkce v bode k P(k <= X <= l) = P(X <= k) - P(X <= l) … rozdil distribucnich funkci v bodech k a l
